library-ification

2020-07-09
技术
约 1426 字 预计阅读 3 分钟

来源：Library-ification，Niko Matsakis，2020-04-09

把 rustc 重构成一组独立库、用 query 系统串起来。这个方向有两层收益。

第一层：分析工具拿得到数据

Prusti、MIRAI、Clippy 这类工具想在类型系统之上叠加额外的分析。理论上 Rust 特别适合做这个：C#/Java 那种到处共享可变别名让分析极难，而 Rust 的借用检查天然把“这个函数可能读改哪些数据”变得清楚——分析工具需要的别名分析，和编译器已经在做的事情对应得很好。
