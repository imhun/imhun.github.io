开发练习

Webassembly Rust 生命游戏

有限宇宙策略

1.跟踪存在事件的宇宙子集，在需要的时候进行扩展。在最坏的情况下，扩展是无限的，将会导致速度变慢，内存不够

2.创建固定大小的宇宙。在边上的单元的邻居数量少于中间的单元，缺点是有些模式在到达边界时会消失

3.创建固定大小，循环的宇宙，在边上的单元拥有宇宙对边的邻居

我们将实现第三种

Rust 和 javascript 接口

最小化WebAssembly内存的复制和拷出

最小化序列化和反序列化，可以通过wasm_bindgen提供的接口，直接实现对象的操作，避免序列化

最小化javascript和webassembly函数的互调

比较好的设计是在WebAssembly 中保存一个大的，持久的rust类型实现的数据结构，然后提供操作接口，供javascript调用，通过这些接口，传输数据，执行大量计算，查询数据，最终返回少量的可拷贝的结果。

通过只返回少量的计算结果，可以避免在javascript gc和webassembly内存之间频繁来回复制或者序列化

生命游戏接口

1.不想在每个时钟周期，拷贝整个宇宙。不想为宇宙中的每个单元分配对象。不想提供跨边界的读取和写入每个单元的接口。

提供一个平面数组来表示宇宙，每个单元一个字节，0表示死亡单元，1表示生存单元，
