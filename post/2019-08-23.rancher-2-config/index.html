Rancher 2.1 gitlab流水线配置

参考文档：https://rancher.com/docs/rancher/v2.x/en/tools/pipelines/configurations/#1-configuring-version-control-providers

  1. pipeline配置

gitlab用户-设置-applications，增加rancher 应用，并授权api,read_repository，然后保存。

配置完成，生成application id及secret，后面需要用到

rancher配置，输入上面生成的应用id和秘钥，并在私有gitlab地址栏输入你的gitlab的域名，点击授权，跳转到gitlab授权页面确认

成功以后，会自动导入授权gitlab用户下面的所有仓库，即完成了gitlab仓库的配置。

代码库流水线设置，示例仓库：https://github.com/rancher/pipeline-example-maven

在代码库根目录加入，.rancher-pipeline.yml，deployment.yaml ,具体配置

Prometheus 监控配置

通过应用商店安装Prometheus，即可启用prometheus和grafana监控

跨项目dns配置

1.配置集群ip

集群ip是一个固定ip,指的是整个k8s集群内部所有服务可见

2.在新的项目中，配置服务发现的dns记录，指向上面配置的集群ip

升级rancher 2

官方文档：https://rancher.com/docs/rancher/v2.x/en/upgrades/upgrades/single-node-upgrade/

https://www.cnrancher.com/docs/rancher/v2.x/cn/upgrades/single-node-upgrade/

#停止当前rancher容器

docker stop priceless_keldysh

#从容器创建数据卷

docker create –volumes-from priceless_keldysh –name rancher-data rancher/rancher:v2.1.6

#启动数据卷，并备份数据到本地文件

docker run –volumes-from rancher-data -v $PWD:/backup busybox tar zcvf /backup/rancher-data-backup-2.1.6-20190407.tar.gz /var/lib/rancher

#拉取最新版本

docker pull rancher/rancher:v2.2.5

#从数据卷启动新版本

docker run -d –volumes-from rancher-data –restart=unless-stopped -p 8080:80 -p 8043:443 rancher/rancher:v2.2.5

#删除老版本rancher容器

#从备份数据恢复rancher

docker run –volumes-from rancher-data \ -v $PWD:/backup busybox sh -c “rm /var/lib/rancher/* -rf \ && tar zxvf /backup/rancher-data-backup-2.1.6-20190407.tar.gz”

清理节点

通过管理面板删除的节点，会自动触发节点清除，等清除结束以后，需要重启节点

如果自动清除失败，可执行手工清除命令如下：

https://rancher.com/docs/rancher/v2.x/en/cluster-admin/cleaning-cluster-nodes/

docker rm -f $(docker ps -qa)

docker volume rm $(sudo docker volume ls -q)

docker system prune -fa

for mount in $(mount | grep tmpfs | grep ‘/var/lib/kubelet’ | awk ‘{ print $3 }’) /var/lib/kubelet /var/lib/rancher; do umount $mount; done

rm -rf /etc/ceph \

/etc/cni \

/etc/kubernetes \

/opt/cni \

/opt/rke \

/run/secrets/kubernetes.io \

/run/calico \

/run/flannel \

/var/lib/calico \

/var/lib/etcd \

/var/lib/cni \

/var/lib/kubelet \

/var/lib/rancher/rke/log \

/var/log/containers \

/var/log/pods \

/var/run/calico
