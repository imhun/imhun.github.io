trait Foo { }
struct Bar<'a> {
x: &'a i32,
}
impl<'a> Foo for Bar<'a> { }
let num = 5;
let obj = Box::new(Bar { x: &num }) as Box<Foo>;

  • The default lifetime of a trait object is ‘static.

  • If we have &‘a X or &‘a mut X, then the default is ‘a.

  • If we have a single T: ‘a clause, then the default is ‘a.

  • If we have multiple T: ‘a-like clauses, then there is no default; we must be explicit. Box<Foo + ‘a> or Box<Foo + ‘static>
