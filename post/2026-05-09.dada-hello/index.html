来源：Hello, Dada!，Niko Matsakis，2026-02-09 系列：Dada

第一个程序不需要 main：

1

println("Hello, Dada!")

省掉 main 是后来才改的。作者说他没想到这个改动会让语言感觉轻这么多——小改动，大收益。取向是“你有权写代码”：样板不该是入门的门槛。

只有一个 String

1

let name: String = "Dada"

类型就是 String。这在 Rust 里会绊住新人——那里字面量是 &'static str，常量和构造出来的字符串混用时要到处写 .to_string() 或者 format!。作者说他更受不了的是这份麻烦本身。

和多数现代语言一样，字符串不可变，可以随意复制：

1
2
3

let name: String = "Dada"
let greeting: String = "Hello, {name}"
let name2: String = name

两处“方便是默认的”

字符串插值是默认开的：

1
2

let name = "Dada"
println("Hello, {name}!")

多行字符串也不用转义拼接。规则是：" 后面紧跟换行时，开头和结尾的换行、以及后续每行的统一空白前缀都会被剥掉；内部换行保留：

1
2
3
4
5
6

let name = "Dada"
println("
    Hello, {name}!

    How are you doing?
")

输出

1
2
3

Hello, Dada!

How are you doing?

两条都来自同一个原则：方便是默认的，最常用的写法应该最短。
