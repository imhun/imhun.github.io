trait OutlinePrint: fmt::Display {
fn outline_print(&self) {
let output = self.to_string();
let len = output.len();
println!("{}", "*".repeat(len + 4));
println!("*{}*", " ".repeat(len + 2));

The Never Type,!, that Never Returns

!：在类型理论中被称为empty type，因为该类型没有值

rust更喜欢称为Never Type，代表该类型用于函数返回类型时，表示函数从不返回(Never return)。

1
2
3

fn bar() -> ! {
// --snip--
}

上面的例子读作：函数bar返回Never，这类函数称之为：发散函数(diverging functions)

!可以强制转换为任意类型

1

panic!的返回类型为!

Dynamically Sized Types &Sized

又叫‘DSTs’ or ‘unsized types’，表示只能在运行时知道大小

比如str,不能为dst类型创建一个值

&str有str的地址及长度。

只能把dst类型放在某种类型的指针后面

1

traits也是dst，只能通过指针使用，&Trait or Box<Trait>

TheSized Trait

表示是否可以在编译时确定类型大小，编译器自动为所有可以在编译时确定大小的类型实现该trait

rust为所有泛型函数的泛型参数隐式添加Sized约束

1
2
3

fn generic<T>(t: T) {
// --snip--
}

实际上相当于

1
2
3

fn generic<T: Sized>(t: T) {
// --snip--
}

默认情况下，泛型函数只接受Sized类型，不过可以通过如下方式放宽约束

1
2
3

fn generic<T: ?Sized>(t: &T) {
// --snip--
}

?Sized表示类型T不一定可以确定大小，因此只能通过指针&T来使用

函数高级特性

函数指针function pointer

1

fn()->T ,fn是一个类型，函数指针实现了Fn, FnMut, and FnOnce，因此可以直接把函数指针作为参数传递给需要闭包的函数，推荐使用泛型及闭包trait来定义函数参数，这样既可以传入函数指针，也可以传入闭包。

只接受函数指针的场景：与没有闭包的外部代码交互时，例如c函数，c里没有闭包

Returning Closures

闭包被表示为trait，因此不能直接作为函数返回值，只能通过trait object来返回

fn returns_closure() -> Box<Fn(i32) -> i32> {
